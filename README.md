## 구현할 기능 목록 (자동차 경주 게임)
### 1. Model: 핵심 객체 구현
Car 객체를 구현하여 자동차의 이름과 현재 위치(position) 상태를 관리한다.

Car 객체에 난수(0~9)를 받아 4 이상일 경우 위치를 1 증가시키는 **전진 기능 (tryMove)**을 구현한다.

MoveRule 객체를 구현하여 **전진 조건(무작위 값 4 이상)**을 판단하는 단 하나의 비즈니스 규칙을 정의한다.

Cars 객체를 구현하여 List<Car> 형태로 전체 자동차 목록을 관리한다.

Cars 객체에 전체 라운드 실행 기능을 구현하여 모든 Car 객체의 이동을 처리한다.

### 2. Model: 우승자 결정 로직
Cars 객체에 최종 우승자 선정 로직을 추가한다.

가장 많이 전진한 최대 전진 거리를 계산한다.

최대 전진 거리를 가진 자동차들의 이름 목록을 반환한다.

### 3. View: 입/출력 기능 구현
InputView 객체를 구현하여 사용자에게 자동차 이름과 시도 횟수를 요청하고 Console.readLine()으로 값을 받는다.

OutputView 객체를 구현하여 각 라운드 실행 결과 (이름과 하이픈(-)으로 위치 표시)를 포매팅하고 출력한다.

OutputView 객체에 최종 우승자 이름을 형식에 맞춰 포매팅하고 출력한다.

### 4. Controller 및 통합
GameController 객체를 구현하여 게임의 전체적인 흐름을 제어한다.

InputView로부터 사용자 입력을 받아 모델을 초기화한다.

지정된 횟수만큼 라운드를 반복 실행하도록 Cars에 지시한다.

라운드별 결과를 OutputView를 통해 출력하고, 최종 우승자 목록을 받아 출력한다.

Application의 main() 메서드를 구성하여 GameController를 실행시킨다.

### 5. Validation: 입력 유효성 검증
사용자 입력에 대한 유효성 검증 로직을 구현하고 적용한다.

자동차 이름: 1자 이상, 5자 이하인지 검증.

자동차 이름: 중복이 발생하지 않았는지 검증.

시도 횟수: 1 이상의 정수인지 검증.

유효하지 않은 값 입력 시 IllegalArgumentException을 발생시킨다.
